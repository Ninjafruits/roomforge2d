Hello, welcome to RoomForge2D! 


~~Introduction
//
RF2D is a simple room designer to help map layouts for your room before you start moving stuff in
and finding out your furniture does not fit.
//

~~ Notes: 
//
You can find the program in the roomforge2d folder, as well as a distribution. exe file if you just wish to run it.
//

~~Version
//
This is in alpha stage, so expect bugs and missing features. However, it bears a functional application to layout.
This could also serve as a very basic game map editor, but it is not intended for that purpose. ONLY COMPATIBLE WITH WINDOWS
//

~~Program features
//
Language:

Python 3

Libraries & Frameworks:

- Tkinter – Native Python GUI toolkit used for building the interactive 2D interface.

- Math – Standard library for geometric calculations (e.g., wall lengths, rotation angles).

- Key Programming Concepts Demonstrated:

- Object-Oriented Programming (OOP) – Encapsulation of functionality into well-structured classes (RoomPlanner, OptionDialog).

- Event-Driven Programming – Dynamic interaction via mouse clicks, keyboard bindings, and canvas events.

- Custom GUI/UX Design – Scrollable and zoomable canvas, real-time previews, tooltips, and dialog-based interaction.

- State Management – Tracks drawing modes, selected elements, and supports undo/redo functionality.

- Canvas Graphics – Dynamic drawing and manipulation of walls, windows, and furniture using the Tkinter canvas system.

- Geometry & Trigonometry – Handles furniture rotation and precise placement with transformations.

- User Input Validation & Dialogs – Uses simpledialog, messagebox, and custom dialogs for controlled user interaction.

- Additional Skills:

- Scalable UI Logic – Zooming and panning support for usability on various screen sizes.

- Undo System – Action tracking and rollback using a custom undo stack.

- Interactive Design Patterns – Drag & drop, tool modes, visual feedback, and snapping (e.g., shift-straight-line drawing).
