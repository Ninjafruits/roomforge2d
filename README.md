🏠 RoomForge2D
  Version 1.2
  A 2D room and interior planner written in pure Python using Tkinter.

📌 Description
  RoomForge2D is a lightweight 2D room planner application that allows users to draw floor plans, place windows, and add customizable furniture. It’s designed to be simple, efficient, and user-friendly — ideal for quick prototyping or conceptual interior design.
  
  This project demonstrates proficiency in:
  
  Tkinter GUI development
  
  Event-driven programming
  
  Geometry, scaling, and transformation algorithms
  
  Interactive canvas manipulation
  
  Clean OOP structure
  
  Undo system and object state tracking

🚀 Features
  Wall Drawing: Click to define room boundaries. Hold Shift to enforce straight lines.
  
  Window Placement: Snap windows to wall segments with customizable sizes.
  
  Furniture: Add circular or rectangular furniture with drag, rotate (R key while dragging), and resize capabilities.
  
  Zooming and Panning: Zoom in/out for precision. Middle-click (mouse button 2) and drag to pan.
  
  Undo / Clear: Undo recent actions or reset the canvas.
  
  Intuitive Editing: Context-sensitive right-click-style options via left-click menu for each item.
  
  Custom Tooltip and Status Display: Helpful UI feedback with a clean interface.
